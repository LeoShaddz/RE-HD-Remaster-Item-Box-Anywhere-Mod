# Resident Evil HD Remaster Item Box Anywhere Mod

This mod allows you to access your item box from anywhere.

Controls: The 'I' key on your keyboard, or the RB + LB buttons on an Xbox controller.

The controls can be customized.

If you’re looking for an approach like that of RE4, RE5 and RE6, this mod might interest you.

PS: This mod was not designed with Real Survival mode in mind.

# Installation

1. Install the Ultimate Asi Loader in in the game's root folder
2. Extract the file "RE.HD.Remaster.Item.Box.Anywhere.Mod.v1.0.zip"
3. Copy the .asi and .ini files into the "scripts" folder
4. Done
